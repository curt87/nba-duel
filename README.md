# 首发五人对决

一个给 NBA 官方 APP 做增长的**组队对战小游戏原型**。用工资帽组建你的首发五人，挑一支真实球队（或者朋友的阵容）打一场，由大模型判断哪一套更可能赢，并讲清楚为什么。

👉 **在线试玩：** https://<你的用户名>.github.io/nba-duel/

---

## 怎么玩

1. **组队** —— 11 档定价 + 100% 工资帽，五个位置各选一人
2. **挑对手** —— 30 支真实球队 / 朋友的挑战码 / 自己手搓一队
3. **看分析** —— 谁更可能赢 + 四步分析过程 + 关键对位

## 两层设计要解决的问题

**第一层：怎么防止"无脑选最强五人"？**

用**分档定价 + 工资帽**：

- 球员按《2026-27 季前球员评级分档》分成 11 档，**档位 = 球员评分的整数部分**（评级 7.9 分 → 7 档，11.4 分 → 11 档）
- **每一档的身价 = 现实中这个级别的球星占工资帽的比例**：顶薪 35% / 33% / 28%，往下是全额中产 10%、迷你中产 7%…… 老将底薪 2%
- 两个顶薪 = 70%，正好还能签三个全额中产（30%），合计 100% —— 这就是真实 NBA 最经典的建队方式
- 而 35% × 3 = 105%，直接超帽 —— **三个顶薪在工资帽下签不出来，现实里也一样**

玩家不需要学任何新规则，用 NBA 自己的常识就能组队。

**第二层：胜负怎么判断？**

**不套规则。** 规则算不出"适配性" —— 它不知道库里场均 26 分但大部分出手是无球跑出来的，也分不清"空间拉得开"和"篮下没人"是两回事。

所以：

- **引擎只提供参考角度** —— 九个观察维度（持球硬解 / 空间拉开 / 内线终结 / 护框 / 外线防守 / 篮板 / 组织串联 / 转换节奏 / 健康续航）的两边数值。明确标注"只是提示可以看哪些角度，不是评分，也不是结论"
- **判断交给大模型** —— 它去看球员的类型和搭配，走完四步分析：**球权与打法 → 对位 → 胜负点 → 调整**
- **不给比分** —— 真实比赛还有替补轮换，只比首发五人，报一个具体比分没有意义

## 技术说明

- **单文件 HTML，零依赖**，手机浏览器打开即玩。`index.html` 就是全部代码
- **球员库是脚本生成的**（248 人，覆盖 30 队），数据口径为 2026-27 开季预测阵容 + 2025-26 常规赛数据
- **大模型**：默认智谱 `glm-4-flash`（免费模型），OpenAI 兼容接口，可自由替换。支持 9 家预置服务商一键切换
- 免费模式默认开启：只有白名单里的免费模型能调用，写死付费模型名会被本地拦截，请求根本发不出去

## 本地运行

直接双击 `index.html` 就能玩，不需要任何服务器。
